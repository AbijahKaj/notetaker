How encryption works

Last updated: 2026-05-22

NoteTaker stores meeting transcripts, speaker labels, and notes in a local SQLite database under ~/Library/Application Support/NoteTaker. By default, that database is encrypted at rest using SQLCipher.

What's encrypted

  • All transcript text
  • Speaker IDs and human-given labels
  • Meeting metadata (titles, timestamps, app context)
  • Your private notes
  • Generated summaries
  • The full-text search index

Encryption is enabled by default. You can toggle it off in Settings → Behavior if you want a plain SQLite file (for example, to inspect it with another tool), but we recommend leaving it on.

What's not encrypted by NoteTaker

  • Raw audio (if you've enabled "Save raw audio locally" in Settings) is written as plain .f32le files alongside the database. Disable that toggle if you don't want raw audio on disk.
  • Crash logs are written by macOS to ~/Library/Application Support/NoteTaker/Crashes in standard format. They never leave your Mac.
  • Application preferences (whitelists, hotkey, LLM choice) live in an unencrypted JSON file.

The encryption key

On first launch, NoteTaker generates a 256-bit random key and stores it in your macOS Keychain under the service NoteTaker with the account db:encryption. Only your user account on this Mac can read it, and access is mediated by the macOS Keychain.

The key is never written to disk in plaintext, never transmitted anywhere, and never visible to the maintainers.

Cipher

NoteTaker uses SQLCipher with the v4 default profile: AES-256 in CBC mode, HMAC-SHA512 for page-level integrity, and PBKDF2-SHA512 with 256,000 iterations for key derivation.

If you lose the key

Because the key never leaves your Keychain, nobody can recover your transcripts if your Keychain is wiped or your Mac dies without a backup. This is the price of "we can't see your data" — we also can't reset your password for you.

Recommendations:

  • Use macOS's built-in iCloud Keychain sync if you want the key to follow you across machines.
  • Time Machine backups capture both the encrypted database and the Keychain — keep them.
  • Export important sessions to Markdown periodically for offline backups you can read without NoteTaker.

Reporting a vulnerability

Please use GitHub's private security advisories rather than a public issue. We aim to respond within a few days.
